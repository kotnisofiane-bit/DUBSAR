# Installation

There is no supported public installation of DUBSAR Personal or the complete
Control Plane at this time.

This repository is the canonical public documentation root. It contains no
Desktop application, private Core, product runtime or installation package.
Source visibility and Git history are not a product installation path.

## Current access boundary

Personal is in active integration / technical development. No public release,
beta invitation, supported-platform list or commercial support is announced.

Control Plane documents required component boundaries. It is not presented
as a generally available organizational platform or a fully qualified live
runtime stack.

Separately available source is linked under
[Technical components](README.md#technical-components). A component's preview,
commands and licence apply only to its own scope. Installing DUBSAR Memory
does not install unified Personal or Control Plane.

## Historical packages

Do not reconstruct the retired `plugins/scribe/` tree, restore an obsolete
Marketplace manifest or mix historical Desktop, runtime and plugin versions
as a current product installation.

The [historical Marketplace record](docs/legacy/marketplace-0.11.1/README.md)
preserves provenance, not a supported package.

## Future distribution

Any release needs an identified component and canonical source, applicable
licence and third-party notices, supported environments, artifact integrity,
credential and privacy boundaries, and validated installation, update,
rollback and removal.

No release date or distribution is promised here. See [Status](STATUS.md),
[Rights](RIGHTS.md), [Security](SECURITY.md) and [Integrity](INTEGRITY.md).
