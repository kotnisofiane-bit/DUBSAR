# Historical DUBSAR diagrams

This folder retains diagrams from an earlier coding-agent product direction.
They are preserved for project history and review, not as the current canonical
product architecture.

The current public direction is documented in:

- [README](../../../README.md);
- [Product and surfaces](../../../PRODUCT_SURFACES.md);
- [Architecture](../../../ARCHITECTURE.md);
- [Current status](../../../STATUS.md).

## Interpretation boundary

The retained images may show host adapters, Claude Code, a local Bridge,
multi-session worktrees, Desktop flows or a Windows beta journey. Those
elements describe earlier experiments.

They must not be interpreted as evidence of:

- a current coding-agent commercial surface;
- an active public or private beta;
- a supported Claude Code, Codex or Cursor integration;
- a supported Windows, Linux or macOS product;
- a public plugin, runtime or installation path;
- publication of private DUBSAR implementation.

The earlier experiments informed DUBSAR's evidence, identity and human-authority
doctrine. The current delivery surfaces are the automated audit portal, coming
soon, and the Professional DUBSAR Audit, available on request.

No mock or historical image in this folder should be presented as a capture of
a currently shipped product.
